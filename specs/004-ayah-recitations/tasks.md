# Tasks: Ayah-by-Ayah Recitations

**Input**: Design documents from `specs/004-ayah-recitations/`

**Organization**: Tasks are grouped by user story (US1–US4 in the spec). **Release is gated on

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependencies on incomplete tasks)
- **[Story]**: Which user story this task belongs to (US1–US4)

## Path Conventions

Single Flutter project at the repository root: `lib/`, `test/`, `tool/`, `integration_test/`,
`android/`, `ios/`, `docs/`. New audio code lives in `lib/features/recitation/`.

## Shared conventions

- **Tests**: tests that need the real Quran data use `openTestReader()` and `loadAppFonts()` from
  `test/support/harness.dart` inside `testWidgets`, wrapping database work in
  `tester.runAsync(...)`. Tests never reach EveryAyah. They use:
  - a localhost `HttpServer` serving generated byte payloads;
  - a fake `AudioEngine` (the interface from T020);
  - a fake `app.mathani/device` channel set with
    `TestDefaultBinaryMessengerBinding.instance.defaultBinaryMessenger.setMockMethodCallHandler`.
- **Named constants**: numbers from research and contracts are named constants, each defined in
  one place:

  | Constant | Value | Defined in |
  | --- | --- | --- |
  | `prefetchAhead` | 3 | `ayah_fetcher.dart` |
  | `cacheLimitBytes` | 100 MB | `ayah_fetcher.dart` |
  | `cacheTrimToBytes` | 90 MB | `ayah_fetcher.dart` |
  | `fetchTimeout` | 15 s | `ayah_fetcher.dart` |
  | `downloadConcurrency` | 2 | `download_queue.dart` |
  | `storageHeadroomBytes` | 50 MB | `download_queue.dart` |
  | `loadingTimeout` | 15 s | `recitation_controller.dart` |
  | `skipMergeWindow` | 300 ms | `recitation_controller.dart` |
  | `endedBannerDuration` | 3 s | `recitation_controller.dart` |
  | `barHeight` | 56 dp | `recitation_bar.dart` |
  | `barSecondRowHeight` | 36 dp | `recitation_bar.dart` |
  | `progressUpdatesPerSecond` | 4 | `download_queue.dart` |
  | `manifestConcurrency` | 4 | `tool/build_recitation_manifest.dart` |
  | `manifestBackoff` | [1 s, 4 s, 16 s] | `tool/build_recitation_manifest.dart` |

- **Recordings are never altered**: no trimming, speed or pitch change, or effects (FR-003).
- **State before platform**: player state changes (`playing`, `paused`, and so on) are set and
  notified **before** awaiting plugin calls, so controls react within 100 ms (FR-011).
- **No startup cost**: nothing in this feature may run before the first reader frame. That
  includes `AudioService.init`, `AudioSession` configuration, catalogue size queries and
  download scans (Principle III).

### Fetcher (contracts/audio-storage.md › Paths, Resolve, Cache limit)

- [X] T017 [P] Write `test/unit/ayah_fetcher_test.dart`, before T018. It uses a localhost `HttpServer` that serves `primary/` and `mirror/` paths with payloads of catalogue sizes and can be told to fail, truncate or delay, plus temp directories for cache and support dirs. Cases:
  1. A valid downloaded file wins over the cache and the network.
  2. A valid cache hit touches mtime and makes no request.
  3. A miss downloads via `.part`, then renames.
  4. A size mismatch from the primary falls back to the mirror.
  5. Both failing throws `FetchError.fetchFailed`.
  6. `networkState == none` throws `FetchError.offline` without a request.
  7. Two concurrent resolves of the same file make one request.
  8. Writing past 100 MB trims the least recently modified files to ≤ 90 MB, never deleting protected files.
  9. `clearCache()` keeps protected files and returns the bytes freed.
  10. Stale `.part` files are deleted by `init()`.
  11. A wrong-size downloaded file is not returned, is deleted, and is reported through `onDamaged`.
  12. Requests carry no `Cookie` header and no identifying headers beyond the default `User-Agent` (FR-023). The server asserts this on every request.
- [X] T018 Implement `lib/features/recitation/ayah_fetcher.dart` (`AyahFetcher`) per `contracts/audio-storage.md`:

On iOS, call `excludeFromBackup` (T014) on the support `recitations` directory when it is created.
  - **Resolve**: `Future<File> resolve(Reciter r, RecitedItem item)`. A basmala resolves 1:1's bytes, from `basmala.mp3` first. `valid()` means the file exists and its length equals the catalogue `bytes`. HTTP uses `dart:io` `HttpClient` with `connectionTimeout` and an idle timeout of `fetchTimeout` (15 s). Errors are `FetchError.offline` or `FetchError.fetchFailed`. In-flight requests are de-duplicated with a `Map<String, Future<File>>`.
  - **Prefetch**: `prefetch(r, List<RecitedItem>)` is cancellable, and `protect(Set<String> paths)` marks the current and next 3 items.
  - **Cache**: LRU trim to `cacheTrimToBytes` when the cache exceeds `cacheLimitBytes`. `clearCache()` returns the bytes freed, and `cacheBytes()` the current size.
  - **Hooks**: `onDamaged(reciter, surah)` is a stream for the download queue. `init()` deletes stale `.part` files and runs on first use, not at startup.
