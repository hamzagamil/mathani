Memorization recognition model: Khatma FastConformer (downloaded on first use, not bundled)

This model is an adapted version of NVIDIA FastConformer-Hybrid PCD Large (ar)
(stt_ar_fastconformer_hybrid_large_pcd_v1.0), by NVIDIA:
https://huggingface.co/nvidia/stt_ar_fastconformer_hybrid_large_pcd_v1.0

Licensed under the Creative Commons Attribution 4.0 International License (CC BY 4.0):
https://creativecommons.org/licenses/by/4.0/

Changes made by Khatma (https://huggingface.co/adnanfet/khatma-model):
only the CTC head is used; the model was exported to ONNX with audio preprocessing inside the
graph, starting from the ONNX export of the Tilawa project v0.2.0 (github.com/yazinsai/tilawa),
which comes from github.com/Cyberistic/offline-quran-validation; it was then quantized, with int4
matrix multiplications and 1x1 convolutions rewritten as int8 MatMulInteger, and repacked.

Changes made by Mathani (tool/export_khatma_model.py): the int8 weights were unpacked and
embedded in a single ONNX file, the graph's audio-length input is now computed from the audio
itself, a vocabulary file was added, and the file is gzip-compressed for download. The model was
not retrained.

The model is provided as is, without warranties of any kind, as stated in the license. Speech
recognition makes mistakes, and it does not check tajweed or harakat.
